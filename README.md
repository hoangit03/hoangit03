## 🚀 Featured Work

**🔹 GASCO — On-Prem Multi-Service RAG Chatbot Platform** *(Solo, AI/Platform Engineer)*
Modular monolith (FastAPI, PostgreSQL, Qdrant, Redis, RabbitMQ/Celery, MinIO) serving ~600 services through an embeddable widget. Built 7-signal service routing, hybrid dense+lexical retrieval with reranking, a 12-state async ingestion pipeline with content-hash idempotency, RBAC with per-service scoping, and eval-gated releases backed by 250+ automated tests.

**🔹 Primora — CRM Chatbot** *(Solo, 1-month build)*
Dual-flow LangGraph system (CustomerGraph + SaleGraph) across 6 intent categories, with tool-calling into the Frappe CRM API and a multi-provider LLM factory (Gemini/OpenAI/DeepSeek). Deployed via Docker Compose + Nginx with GitLab CI/CD.

**🔹 RealEstateOS — Multi-Agent Asset Management Platform** *(Team of 2, Core AI/Agent Logic)*
LangGraph supervisor graph coordinating 8 specialized domain agents with stage-aware orchestration, a data-freshness gate, composite risk scoring (NPV/IRR/funding-gap), anomaly detection, and HITL approval routing for high-materiality actions.

**🔹 Internal Policy & Onboarding RAG Chatbot** *(Team of 3, Core AI Logic)*
RAG pipeline on Qwen2.5-7B-AWQ/vLLM, evaluated with RAGAS at 0.8+ across faithfulness, answer relevancy, and context precision. Unified Smart Router consolidating intent detection, keyword extraction, and query rewriting into a single LLM call, plus RBAC-aware retrieval and semantic caching.
